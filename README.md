# 香港茶餐廳 —— 店長營業模式

一個以香港茶餐廳「店長營業」為情境的小學數學遊戲。學生扮演店長，在 15 分鐘限時營業期間接待客人、按點單要求配餐、列出食物開銷算式、列出完整找錢算式、判斷運算次序、填寫找錢答案，完成越多訂單營業額越高。

整個遊戲是單一 `index.html`，不需要安裝、不需要伺服器，離線也可以玩。

---

## 快速開始

- **最簡單**：雙擊 `index.html`，用 Chrome、Edge 或 Safari 開啟。
- **本地伺服器（可選）**：在此資料夾執行 `python -m http.server 8000`，再瀏覽 <http://localhost:8000/>。
- **全班使用**：把 `index.html` 上載到 GitHub Pages、Netlify Drop 等靜態託管即可；不需要後端。
- **語言**：按「中文 / EN」切換繁體中文與英文，選擇會記住。
- **自動測試**：在網址加上 `?test=1`，頁面會執行數學、訂單、環保與算式結構檢查，畫面左下角顯示 `Self-test: N passed, 0 failed`。

> 遊戲不使用外部字體、圖片或函式庫；食物、店長標誌、客人造型都是內嵌 SVG 卡通圖，不依賴裝置 Emoji 字型。

## 三個關卡

| 關卡 | 營業時間 | 學習重點 |
| --- | --- | --- |
| **基礎：實習店長** | 15 分鐘 | 圓括號 · 三個數加減混合運算。每單兩款食物、每款 1 份。 |
| **進階：正式店長** | 15 分鐘 | 乘加乘減混合運算。每單至少一款 2 份或以上，用乘法表示份數。 |
| **挑戰：環保達人** | 15 分鐘 | 四則運算 · 環保。每單由客人指定食物類別與份數，需兼顧包裝環保。 |

三個關卡由淺入深。**基礎與進階模式不含任何環保要求**；只有挑戰模式顯示環保值、包裝與環保要求。

## 店長營業模式

1. **接待客人**：客人以卡通造型顯示在頁面上方，用對話框提出點單要求（指定食物、份數、付款金額；挑戰模式另含食物類別、堂食／外賣與環保要求）。
2. **按餐牌配餐**：所有食物顯示在同一頁面（響應式網格，單頁捲動，無分頁），按「加入餐盤」配餐，可加減份數或移除。選餐時不顯示總價。挑戰模式另有環保程度篩選（高／一般／多塑膠），可與食物分類組合使用，再次點擊同一按鈕即可取消。
3. **結賬前檢查**：按「結賬」後先核對餐盤是否符合客人要求（份數、款式、環保值、預算等），不符合會給具體提示，但不會直接給答案。
4. **四步計算流程**：符合要求後進入翻頁式計算（見下）。
5. **完成訂單**：四步完成後顯示電子小票，營業額增加，接待下一位客人。
6. **限時營業**：15 分鐘時間結束後顯示營業報告。

---

## 四步計算流程

每次只顯示一個任務，答對後才可進入下一步，不能跳過。**每一步都顯示同一張訂單摘要**（客人、食物、份數、單價、付款金額）。

1. **第一步「計算食物開銷」** — 用數字、括號、`+ − × ÷` 按鈕列式。多份相同食物必須用乘法。核對是否漏計食物、份數是否正確、運算符號、結果是否等於開銷。
2. **第二步「列出找錢算式」** — 列出 `付款金額 − (完整商品算式)`。**必須包含第一步的商品算式**，不能直接寫已算好的總額（例如 `50 − 23` 不通過，正確是 `50 − (2 × 8 + 7)`）。核對是否用減法、付款金額是否在減號前、是否用圓括號包住商品算式、被減數是否調轉、是否用總額取代商品算式。
3. **第三步「先計算哪一步？」** — 顯示第二步的找錢算式，判斷括號內應先算哪一步（基礎：加減；進階：先乘；挑戰：四則混合、先乘除後加減）。除數不會為零。
4. **第四步「計算找錢答案」** — 只填寫找錢金額（整數；挑戰模式有需要時可接受小數）。不再要求重列完整算式。

系統核對時不只比較最終數值，還會檢查算式結構（數字、份數、乘法、減法方向、圓括號位置、運算次序、是否保留商品算式）。數值碰巧相同但列式錯誤不會過關。

## 提示系統

- 所有計算步驟的**標題下方沒有提示文字**。
- 每一步在計算框／答案框下方有一個「顯示提示」按鈕，初始狀態為隱藏。
- 按下「顯示提示」後提示才展開，按鈕文字改為「隱藏提示」，再次按下收起。

- 提示只提供思考方向，不直接顯示答案。

## 營業額與環保值計算

- **營業額** = 所有成功完成訂單的食物總價相加。找錢金額不計入營業額。
- **未完成訂單**：時間結束時仍未完成的訂單，不計入完成訂單數、不計入營業額；但已完成的步驟會計入學習數據與錯誤分析。

### 包裝環保分（挑戰關卡）

| 包裝 | 每份環保分 |
| --- | ---: |
| 紙袋、沒有獨立膠盒、沒有包裝（堂食） | 3 |
| 紙杯、荷葉、紙包飲品 | 2 |
| 膠杯、膠盒 | 1 |
| 膠樽、發泡膠盒 | 0 |

環保值 = 每款食物的包裝環保分 × 份數，再全部相加。

挑戰模式分為兩種要求：

- **堂食**：全部餐點須為無包裝堂食餐碟／杯裝，不可有紙袋、紙杯或塑膠包裝。
- **外賣**：不可有發泡膠盒或膠樽（環保分 0），且全單環保總分須達 7 分或以上。

數學正確但環保要求不符時，訂單不能完成，系統會提示重新考慮包裝或食物選擇。

### 環保營業評級（挑戰模式營業結束後）

| 條件 | 評級 |
| --- | --- |
| 營業額高，所有訂單環保達標 | 綠色五星店長 |
| 80% 或以上訂單環保達標 | 環保模範店長 |
| 60% 或以上訂單環保達標 | 綠色實習店長 |
| 少於 60% | 環保仍需努力 |

## 店長排行榜

- 每個關卡各有排行榜，按營業額、正確率、完成訂單數排列。
- 排行榜同時顯示本地店長帳號、訪客紀錄，以及內建的示範同學成績（僅為遊戲示例資料）。

## 店長個人數據與錯誤分析

首頁的「店長個人數據」會顯示：

- **數據總覽**：店長名稱、頭像、累積營業次數、完成訂單、營業額、整體正確率、最佳連續正確、已解鎖成就數、最近登入時間。
- **各關卡數據**：三個關卡的營業次數、完成訂單、最高／平均營業額、最佳訂單數、題目數、正確率、平均完成時間、最近遊玩日期。
- **錯誤分析**：各步驟錯誤次數（選食物、算開銷、算找錢、運算次序、填答案、環保要求）及常見錯誤模式（漏計食物、份數錯誤、未用乘法、符號錯誤、被減數調轉、漏用圓括號、用總額取代算式、先加後乘、進退位、環保不足等）。
- **個人化反饋**：根據數據生成針對性建議（例如「你有時會在找錢算式中直接寫商品總額」），不會直接顯示未完成題目的答案。

## 帳號與資料保存

- **本地帳號**：可建立多個店長帳號，每個帳號資料互相獨立；支援建立、登入、登出、切換、改名、選頭像、設定四位數字 PIN、刪除。
- **儲存方式**：使用瀏覽器 `localStorage`（鍵名以 `cct_v5_` 開頭）保存，重新整理後紀錄不會消失。
- **訪客模式**：可試玩所有關卡，但不會永久保存個人紀錄；訪客成績可用於排行榜。
- **PIN 安全**：PIN 使用瀏覽器 Web Crypto API（SHA-256）產生雜湊值，不會以明文寫入資料。
- **匯出／匯入**：可把個人紀錄匯出為 JSON 檔備份，也可匯入還原。

> ⚠️ **重要**：此帳號只保存在目前裝置和瀏覽器，不是網上帳號。清除瀏覽器資料可能會刪除紀錄，建議定期匯出備份。

---

## 清除、匯出及匯入紀錄

- **匯出**：帳號頁 →「匯出個人紀錄」，下載 `.json` 備份檔。
- **匯入**：帳號頁 →「匯入個人紀錄」，選擇備份檔還原。
- **清除**：刪除帳號會移除該帳號的所有紀錄；清除瀏覽器的網站資料（Cookie 與網站數據）也會移除本地儲存的紀錄。

## 無障礙與技術

- 響應式版面：桌面、平板、手機均可用；手機版餐盤可捲動、結賬按鈕不被遮擋。
- 基本字級不少於 18px，按鈕點擊範圍足夠，顏色非唯一提示方式。
- 所有 SVG 圖片提供文字標籤；對話框與訂單摘要可由螢幕閱讀器讀出。
- 支援鍵盤操作（Tab、Enter、Space、Escape）及清晰焦點框；翻頁後焦點移到新步驟標題。
- 提示按鈕提供正確的 `aria-expanded` 狀態。
- 支援 `prefers-reduced-motion`：啟用後取消翻頁動畫，改用直接切換。
- 計時器最後 30 秒改變顏色但不會快速閃爍。
- 長算式自動換行並縮小字級，不溢出顯示框。
- 單一 HTML 檔、零外部依賴，可離線使用。

## 自動測試（?test=1）

加上 `?test=1` 會執行以下檢查，全部通過時畫面顯示 `Self-test: 48 passed, 0 failed`：

- **基礎數學**：加減混合、乘除混合、圓括號合法性、除以零。
- **訂單生成**：基礎／進階／挑戰的款式、份數與推薦模式。
- **環保規則**：堂食無包裝組合、外賣環保總分、膠盒與膠樽判定。
- **算式結構**：正確算式求值、被減數調轉、同價合併乘法、連加被攔截、第二步必須保留商品算式。
- **分步計算**：第三步動態目標運算、化簡後算式、直接跳轉第四頁，以及第四頁只顯示化簡結果、不再顯示原算式。
- **環保篩選**：僅挑戰模式顯示三個環保篩選按鈕，各級數量、分類＋環保組合篩選、再次點擊取消、選「全部」同步重設。
- **規則彈窗**：起始頁的規則彈窗不顯示關卡流程提示，難度頁的規則彈窗保留關卡規則。

## 修改內容

- **改營業時間**：修改 `LEVELS` 各關卡的 `duration`（秒）。目前三關卡均為 900。
- **加食物**：在 `FOODS` 陣列加入物件，需有 `id`、`name`、`price`、`packaging`、`eco`、`tags` 等雙語欄位。
- **改環保規則**：修改 `evaluateChallengeEco` 及挑戰訂單模板。
- **改提示文字**：修改 `STR` 內的雙語文字（`flowStep1Hint`、`flowStep2Hint` 等）。
- **改樣式**：所有 CSS 都在 `<style>` 內。

## 已知限制

- 價格和餐牌是固定資料，沒有隨機價格或優惠券。
- 主遊戲以整數為主，小數只建議用於延伸活動。
- 帳號資料只存於本地瀏覽器，不是跨裝置雲端同步；換裝置或清除瀏覽器資料會遺失（可用匯出備份）。
- 排行榜的示範同學成績是內建示例資料，不是真實學生紀錄。
- 翻頁動畫在啟用 `prefers-reduced-motion` 時會停用。
- 客人造型與食物圖案為內嵌 SVG，顯示不依賴作業系統 Emoji 字型。

## 備註

本遊戲為 MTH6133 小組演示與課堂試教而設計。重點不是「答對一個數字」，而是讓學生在香港茶餐廳店長情境中：

1. 按照客人要求完成訂單；
2. 先列出商品開銷算式，再把商品算式完整放入找錢算式中；
3. 判斷運算次序，理解圓括號與先乘後加減；
4. 最後只填寫找錢答案；
5. 出錯時根據（自行點開的）提示重算，而不是直接找答案；
6. 在挑戰模式中兼顧營業額與環保決策。

歡迎按班級需要調整餐牌、價格、關卡條件和提示文字。
